= hpm-json-rsr — Roadmap
v0.1.0-dev, 2026-05-28
:toc: left
:toclevels: 2

== v0.1 — Parse + escape (current)

*Status: done in scaffold; awaiting CI / packaging.*

* [x] RSR layout (src/abi/, ffi/zig/)
* [x] Idris2 ABI: Types + Foreign
* [x] Zig FFI: parse / free / type / bool / int / float / string /
  object_get / array_len / array_get / escape_string
* [x] Zig test suite covering: flat object lookup, nested object
  lookup, array indexing, type detection, malformed input, escaping
  edge cases, size-queries
* [ ] Generated C header `generated/abi/hpm_json.h`
* [ ] CI: `zig build test` on every PR

== v0.2 — Builder API
